# LOPINK CULL

Windows desktop photo culling tool built with C# WinForms and .NET 8.

See the project archive `LOPINK_CULL_CSharp_Windows_Project.zip` for source files and build instructions. The repository also includes a GitHub Actions workflow to build a self-contained Windows x64 EXE.

Note: The EXE is produced by the workflow; this upload contains source code, not a prebuilt executable.
